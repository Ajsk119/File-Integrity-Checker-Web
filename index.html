How does this work?

What is a hash?
A hash is a fixed-length fingerprint of a file's contents. SHA-256 always produces a 64-character string. Change even one byte of the file and the entire hash changes completely.
Are my files uploaded to a server?
Yes — files are sent to the server to compute their hashes, but nothing is stored on disk. Everything stays in memory and is cleared when you reset or close the tab.
Which algorithm should I use?
SHA-256 is the safe default. It's fast, widely trusted, and has no known vulnerabilities. Use SHA-512 if you need extra assurance. Avoid MD5 for anything security-related.
Why should I avoid MD5?
MD5 is vulnerable to collision attacks, where two different files can produce the same hash. This makes it unsuitable for security-sensitive applications.
Can I use this for folders?
Not directly, but you can create a .zip archive of your folder and upload that. Just remember to use the same .zip file for both baseline and verification.
Is this secure?
This tool is designed for convenience and basic integrity checking, not for high-security use cases. Don't rely on it to protect sensitive data or against sophisticated attackers.
